Benchmarking

Benchmark a method against a dataset adapter and split while preserving missing-scene handling and metric configuration in the output.

Supported Datasets

DatasetGTAdapter flag
scannetmesh—
replicamesh—
dtupoint cloud—
tanks_templespoint cloud--subset
eth3dmesh / point cloud--track
tum_rgbd— (depth/poses only)—

Dataset Checks

e3r datasets list
e3r datasets show scannet
e3r datasets validate scannet \
  --root /data/scannet \
  --split /data/scannet/splits/scannetv2_test.txt

Run a Split

The generic e3r benchmark run <dataset> command works with any registered adapter. Pass adapter overrides with -o key=value. 

e3r benchmark run scannet outputs/scannet \
  --root /data/scannet \
  --split /data/scannet/splits/scannetv2_test.txt \
  --thresholds 0.05 --workers 8 \
  --out results.json --csv results.csv

e3r benchmark run dtu outputs/dtu \
  --root /data/dtu

e3r benchmark run eth3d outputs/eth3d \
  --root /data/eth3d --track dslr

e3r benchmark run tanks_temples outputs/tnt \
  --root /data/tnt --subset training

Prediction Discovery

eval3r looks for eval3r_prediction.json first. It then falls back to common mesh names such as <scene>/mesh.ply, <scene>/<scene>_mesh.ply, and <scene>/<scene>.ply. 

e3r benchmark run scannet outputs/scannet \
  --root /data/scannet \
  --geometry-pattern "<scene>/out/final.ply"

Summaries

Benchmark output includes a summary over successful scenes and summary_all over every requested scene. Missing or failed scenes are filled with configured defaults so leaderboard-style numbers remain reproducible.
