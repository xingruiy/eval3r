Overview Getting Started Prediction Format CLI Benchmarking

CLI

The e3r command validates predictions, computes metrics, renders artifacts, and runs dataset benchmarks.

Common Commands

e3r validate outputs/scannet/scene0799_00
e3r inspect outputs/scannet/scene0799_00
e3r version

Geometry Metrics

e3r metric all outputs/scannet/scene0799_00 \
  --gt /data/scannet/scene0799_00/gt_mesh.ply \
  --align none \
  --samples 200000 \
  --seed 42 \
  --thresholds 0.05 \
  --chamfer-variant l1_mean_bidirectional

Rendering

e3r render mesh outputs/scannet/scene0799_00/geometry/pred_mesh.ply \
  --out render.png \
  --headless

Alignment Modes

Mode Behavior
noneNo alignment. This is the default.
scaleIsotropic scale only.
se3Rigid rotation and translation.
sim3Scale, rotation, and translation.
icpPoint-to-point ICP initialized from identity.
